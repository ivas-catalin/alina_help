Java Applets

These applets were designed to help students understand a wide range of topics covered in introductory statistics.


Sample from a Population

This applet allows the user to select samples of various sizes from a wide range of population shapes including uniform, bell shaped, skewed and binary (including a range of values for the probability of a 1) populations. In addition, one can alter any of the default populations to create a custom distribution by simply dragging the mouse over the population. Small samples are drawn in an animated fashion to help students understand the basic idea of sampling. Larger samples are drawn in an unanimated fashion so that the characteristics of larger samples can be quickly compared to population characteristics.


Sampling Distributions

This applet bootstraps off the Sample from a Population applet by adding the values of user selected statistics for each sample. One can study the distribution of various statistics and see how characteristics of the sampling distribution such as center and spread are affected by the sample size and population shape. One can also compare sampling distributions of different statistics such as the sample mean and the sample median.


Random Numbers

This applet can be used to select a random sample from a range of integer values defined by the user. One can use the applet to study basic probability by considering the relative frequency of particular outcomes among the samples. The applet can also be used to select samples from a list of values for a hands-on sampling activity.


Long Run Probability Demonstrations

There are six of these applets which simulate the rolling of a die, flipping of a coin and the ups and downs of the stock market. Each activity can be simulated a user specified number of times in an animated or unanimated fashion. The relative frequency of an event of interest is plotted versus the number of simulations. As the number of simulations increases, the convergence of the relative frequency to the true probability of the event will be evident.

Mean Versus Median

This applet allows users to interactively construct a data set by clicking on a graphic which displays the mean and median of the data. Using the applet, one can study the effects of shape and outliers on the mean and the median.


Standard Deviation

This applet provides a similar experience with the standard deviation. In this edition, this applet is also offered in a stacked form so that data sets with different standard deviations can be easily compared.


Confidence Intervals for a Proportion

This applet allows the user to simulate 95% and 99% confidence intervals for a population proportion. The confidence intervals are plotted illustrating their relationship in terms of width and their random nature. The sample size and the true underlying proportion are specified by the user. The effect of these values on the coverage probabilities tabled in the applet can be studied.


Confidence Intervals for a Mean

The first applet can be used to show how sample size and distributional shape impact the performance of classic t intervals for the mean. The second applet allows one to compare the performance of z and t intervals for different distributional shapes and sample sizes.

Confidence Intervals for a Mean (the Impact of Confidence Level)

Confidence Intervals for a Mean (the Impact of not Knowing the Standard Deviation)



These applets allow users to understand how the underlying assumptions impact the performance of hypothesis tests. They plot test statistics and corresponding P-values for data generated under different user supplied conditions. Tabled rejection proportions allow users to determine how the conditions specified affect the true level of significance for the tests.

Hypothesis Tests for a Proportion

Hypothesis Tests for a Mean



Correlation by Eye

The correlation by eye applet allows the user to repeatedly guess the value of the correlation coefficient based on a scatter plot of simulated data. In addition, users can add and delete points in order to see how these actions affect the correlation coefficient.


Regression by eye

This applet allows the user to attempt to interactively determine the regression line for simulated data.


Binomial Distribution

This applet generates samples from the binomial distribution at user specified parameter values. By varying the parameters, the user can develop an understanding of how these parameters impact the binomial distribution.
